## Featured projects

### [Appointment No-Show Analyzer](https://github.com/lukola123/appointment-noshow-analyzer)
Predicts outpatient no-show risk across 106k appointments, converts it into
a daily reliability score, and optimizes reminder targeting under a fixed
staff budget. Calibrated gradient boosting (0.735 AUC), inverse propensity
weighting, and T-learner uplift modeling, wrapped in a Streamlit dashboard.

Notable finding: the population-average effect of SMS reminders is
statistically indistinguishable from zero — but roughly 55% of patients show
positive individual uplift, turning a blanket reminder policy into a
targeting problem.

### [Health Insurance Claim Review Agent](https://github.com/lukola123/insurance-claim-review-agent)
LangGraph ReAct agent that reviews medical claims against policy rules and
CPT/ICD-10 code sets, with swappable LLM backends. 13/14 on a held-out
validation set.
