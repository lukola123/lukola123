# Insurance Claim Coverage Agent (Open-Source Replica)

A LangGraph ReAct agent that evaluates insurance claims against policy rules
and recommends APPROVE or ROUTE FOR REVIEW. Built entirely with synthetic
data — no real patient information.

## Setup

```bash
# 1. Create a virtual environment
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure your LLM provider
cp .env
# edit .env: set LLM_PROVIDER and the relevant API key
```

### Choosing a provider
- **anthropic** (recommended): get a key at https://console.anthropic.com,
  also install `pip install langchain-anthropic`
- **openai**: get a key at https://platform.openai.com,
  also install `pip install langchain-openai`
- **ollama** (free, local, no key): install Ollama from https://ollama.com,
  run `ollama pull llama3.1`, then `pip install langchain-ollama`.
  Note: smaller local models can be less reliable at multi-step tool-calling
  than hosted frontier models — expect more "ROUTE FOR REVIEW" fallbacks.

## Regenerate synthetic data (optional)

```bash
python generate_data.py
```

This recreates everything in `Data/`: reference codes, policies, validation
records (with a reference answer key), and test records.

## Run the agent

```bash
python run_agent.py
```

This will:
1. Run the agent over `Data/validation_records.json`
2. Compare its decisions to `Data/validation_reference_results.csv` -> `validation_comparison.csv`
3. Run the agent over `Data/test_records.json` -> `submission.csv`

## Project structure

```

│   ├── tools.py       # summarize_patient_record, summarize_policy_guidelines, check_claim_coverage

```

## Notes on the synthetic data

All patient/policy data is randomly generated (`generate_data.py`, seeded for
reproducibility) and loosely mimics the shape of real claims data: CPT
procedure codes, ICD-10 diagnosis codes, age/gender rules, and
preauthorization flags. `validation_reference_results.csv` is generated by a
simple deterministic rule-checker — it's a sanity-check baseline, not a
clinical or legal ground truth.
